# ADR-007. Base de la capa de Métodos Numéricos

Estado: propuesto por Métodos Numéricos. Reemplaza la versión anterior de este documento.

## Contexto

El líder aprobó el modelo matemático v0.2 y el registro de decisiones v1.9. Allí se define
que el proyecto trabaja en 2D y 3D, usa Random Walker y resuelve el sistema solo con SOR.
La versión anterior de este documento proponía otras ideas, como conservar cuatro métodos
y cambiar el orden de recorrido de SOR. Esas ideas no coinciden con lo aprobado y se
retiran.

## Decisión

1. La capa 4 recibe únicamente el sistema lineal y la configuración de SOR. No trabaja con
   imágenes, semillas ni peticiones web, y funciona igual en 2D y en 3D.
2. El cálculo del residuo y del criterio de parada está en el archivo residuo.py. El
   criterio se calcula una sola vez, antes de empezar a iterar.
3. SOR recorrerá las incógnitas en el orden fijo que define el modelo matemático.
4. Las pruebas usan volúmenes sintéticos construidos con las mismas reglas del modelo. La
   solución exacta de SciPy solo se usa para comparar resultados dentro de las pruebas.
5. Otras mejoras, como el recorrido rojo-negro o el cálculo automático de omega, quedan
   como posibles experimentos. Solo se adoptarían con pruebas que las respalden y con
   aprobación del líder.

## Consecuencias

- La capa 4 queda lista para implementar SOR sin cambiar los contratos del equipo.
- Las propiedades de la matriz que exige el modelo quedan comprobadas con pruebas
  automáticas.
- Falta implementar SOR y medir cómo influyen omega y el tamaño del sistema.
