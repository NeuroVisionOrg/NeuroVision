# ADR-007 — Segmentación 3D con Random Walker y solo SOR

**Estado:** Propuesto por el ingeniero numérico; pendiente de aprobación del equipo.

## Contexto

El alcance del proyecto cambió: el tumor se modelará en 3D y las tecnologías del backend
son FastAPI, Pillow, NumPy y SciPy, con Canvas en la interfaz. De los cuatro métodos
iterativos previstos solo se implementará SOR.

## Decisión

1. El volumen se forma apilando cortes 2D JPG/PNG del mismo tamaño; el grafo usa
   6-conectividad.
2. El modelo sigue siendo Random Walker binario: $`A = L_{UU}`$ y $`b = -L_{UM}\,x_M`$
   (`docs/modelo_matematico.md`).
3. La capa 4 implementa SOR con dos ordenamientos (`natural` y `rojo_negro`) y estima el
   `omega` óptimo con la fórmula de Young y el método de potencias.
4. Los contratos `SolverConfig` y `SolverResult` no cambian. `SolverMethod` conserva sus
   cuatro valores para no romper contratos, pero solo `SOR` tiene implementación.

## Consecuencias

- La capa 4 no depende de que el problema sea 2D o 3D.
- El ordenamiento rojo-negro es necesario para que un volumen de $`64^3`$ vóxeles se
  resuelva en segundos con Python y NumPy.
- Falta adaptar a 3D `ImageData`, `ROISelection` y `Seed` (contratos compartidos), y la
  construcción del sistema en capa 3.
