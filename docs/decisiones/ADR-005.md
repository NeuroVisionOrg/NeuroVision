# ADR-005 — Modelo Random Walker 2D

> **Estado actualizado (26 de noviembre de 2026):** antecedente histórico. Se conserva la formulación binaria de Random Walker y las condiciones de validez del Laplaciano. La exclusividad 2D, los cuatro solucionadores y la comparación entre métodos quedaron superados por las decisiones aprobadas por el líder. El contenido original se conserva debajo para trazabilidad. ADR-007 está propuesto en la rama de Métodos Numéricos; deberá reconciliarse con este alcance antes de integrarlo.

**Estado:** Seleccionado conceptualmente para implementación y validación experimental; rendimiento aún no validado.

## Contexto

El proyecto académico exige resolver sistemas lineales Ax=b usando Jacobi, Gauss-Seidel, SOR y SSOR para segmentar regiones en resonancias magnéticas 2D.

## Decisión

Usar Random Walker binario con ROI rectangular, semillas FG/BG, grafo de cuatro vecinos, Laplaciano ponderado y sistema \(L_{UU}p_U=-L_{UM}p_M\). Comparar los cuatro métodos propios sobre la misma matriz CSR de tipo float64, con un criterio de residuo común.

## Condiciones

Revisar pesos positivos, conectividad con semillas, matriz SPD, justificación específica de Jacobi y viabilidad de tamaño de ROI. No atribuir capacidad diagnóstica al software.

## Consecuencias

Permite pruebas numéricas aisladas y comparación justa. El tamaño máximo, beta, omega y calidad de las máscaras sobre imágenes reales quedan pendientes de experimentos.
