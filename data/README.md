# Datos de pruebas

Versionar únicamente datos sintéticos reproducibles, pequeños y necesarios para pruebas. Mantener fuera del repositorio los ZIP, resonancias, máscaras de referencia y otros datos médicos de investigación; verificar licencia y autorización antes de usarlos localmente. Nunca publicar información de pacientes ni datos identificables.

Los candidatos para el piloto, los formatos y la inspección de los archivos se describen en [Anexo_validacion_datos.md](../docs/Anexo_validacion_datos.md). La referencia se reserva para evaluación, no para generar la máscara que será evaluada. Una imagen o volumen de investigación no equivale a una validación clínica.
